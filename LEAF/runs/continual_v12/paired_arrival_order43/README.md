# 固定顺序 43 的接入时成对实验

OpenBMI → FACED → BCIC IV-2a。每个目标任务在刚接入时评估，使用完整开发验证划分。三套专家分别来自 seed 0、1、2。每一套专家均使用同一组标签、类别描述、嵌套校准行、验证行和固定合并采样随机数。32 条预算从原系数重建，复验原来的 64 条验证探针。512 条预算从第一位专家重新起步、重新学习系数与共享接口。两预算沿用每步每任务每子集最多 4 条、12 轮、最后六轮平均。IV-2a 接入时旧记忆最多 1,024 条。

① 新专家 backbone 上独立拟合当前任务读出；② 在合并后的 backbone 上按相同规则独立拟合；③ 同一合并 backbone 的实际共享读出。①、②使用相同混合教师目标、分支均值池化、冻结的 MPNet 原型、零初始化、λ=0.001 和至多 20 步共轭梯度。③从旧共享投影出发，使用新旧数据、相同 λ 和三步校准。② 是目标任务专用的诊断参照。② 与③之差包含共享目标、初始化、回放和求解方式的综合影响。
