# 四专家小样本机制试验

专家权重取 seed 0。每次到达使用 32 条分层训练 EEG，每个 support 或 query 批次最多 4 条。每任务固定 64 条分层验证 EEG 作探针，全程使用公开任务与候选类别。PCG64 对 [MI_BCIC_IV2a, MI_OpenBMI, EMO_FACED, EMO_SEED_3_seg4] 抽取三条顺序，顺序种子为 17、29、43。三条顺序中 FACED 均第二个到达。使用 v1.2 原始均值池化、λ=0.001、三步校准和第 7–12 轮系数平均；单专家使用 20 步以内的共轭梯度。各方法、各顺序的开发验证行相同，测试集未读取。

| 方法 | 顺序 17 | 顺序 29 | 顺序 43 | 三顺序均值 |
|---|---:|---:|---:|---:|
| 均匀合并，加接口校准 | 43.61% | 35.27% | 45.38% | 41.42% |
| 普通新旧 CE，张量系数 | 44.43% | 37.04% | 45.73% | 42.40% |
| 逐任务惩罚，临时接口停止梯度 | 44.04% | 37.04% | 46.49% | 42.52% |
| 逐任务惩罚，完整校准梯度 | 44.04% | 37.04% | 46.49% | 42.52% |

表内为最终四任务等权平均 BAcc。学习系数的方法每条顺序共 72 次 Adam 更新；普通 CE 无需反传临时接口，未匹配实际计算成本。均匀合并仅拟合接口。导出前后分数已检查，各阶段平均的 303 对张量系数均可由六个轮末状态复算。完整对停止梯度的最终系数最大绝对差在三条顺序分别为 0.0397、0.0301、0.0490。目前开发探针未测到穿过校准步骤的额外 BAcc 收益。完整方法比普通 CE 平均高 0.12 个百分点，同一方法的顺序差异可超过 9 个百分点。这次使用一个专家 seed、小样本和同一组验证探针，未与同架构 Joint 或官方测试对比。
